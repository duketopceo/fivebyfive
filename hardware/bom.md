# Bill of Materials (BOM)

| Component | Quantity | Notes / Recommendations |
|---|---|---|
| **RP2040 Controller** | 1 | Raspberry Pi Pico, Waveshare RP2040-Zero, or Pro Micro RP2040 |
| **Mechanical Switches** | 5 | Cherry MX / Gateron / Kailh Box / Kailh Choc V1/V2 |
| **Keycaps** | 5 | 1u Keycaps (DSA, XDA, or OEM profile) |
| **Rotary Encoders** | 5 | EC11 20-pulse / 20-detent with integrated push switch |
| **Knobs / Dials** | 5 | 15-20mm knurled aluminum knobs (6mm D-shaft or knurled shaft) |
| **Switch Diodes** | 10 | 1N4148 Axial Diodes (5 for switches + 5 for encoder buttons) |
| **Solid Core Wire** | 1 spool | 24-28 AWG wire for matrix and jumper routing |
| **Case Screws** | 4-6 | M2 or M3 socket head screws (8-12mm length) |
| **Heatset Inserts** | 4-6 | M2/M3 brass heatset inserts (for 3D printed case) |
| **Rubber Feet** | 4 | 3M silicone non-slip bumpons |
